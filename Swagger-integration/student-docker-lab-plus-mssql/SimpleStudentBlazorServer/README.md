# SimpleStudentBlazorServer

The Students frontend built with **Blazor** (.NET 8 Blazor Web App), render mode **Interactive Server**.
It calls the same API as the Razor Pages frontend (`SimpleStudentFrontend`) and the PHP frontend —
with the same typed client generated from `swagger.json` — and works with the **.NET, PHP and Python APIs**.
Lietuviškai: [README_LT.md](README_LT.md).

## How it works

```
Browser ──SignalR (WebSocket)──► Blazor Server container ──HTTP + JSON──► API (.NET / PHP / Python)
         ◄── only the changed     (components run here,                    
             parts of the page)    IStudentApiClient calls the API)
```

- The **components run on the server**. The browser keeps a SignalR connection open, sends clicks and
  key presses, and receives only the parts of the page that changed — no full page reloads.
- The **server calls the API**, like Razor Pages does, so the API does not need CORS and the API
  addresses can be internal Docker names (`http://simplestudentapi:8080`).
- Every browser tab has its own state on the server (a *circuit*). If the connection drops, the page
  shows "Attempting to reconnect…".

## What it shows (compared with the Razor Pages frontend)

| Feature | Where |
|---|---|
| **API switcher** (.NET / PHP / Python) – the data reloads, the page does not | `Components/Layout/ApiSwitcher.razor`, `Services/ApiConnection.cs` |
| **Live search** – the table is filtered on every key press | `Components/Pages/Students.razor` (`@bind:event="oninput"`) |
| **Delete confirmation inside the row** – no browser dialog, no reload | `Components/Pages/Students.razor` |
| **Validation while typing** – rules come from swagger.json (`[Required]`, `[StringLength]`, `[Range]` in the generated `Student` class) | `Components/Shared/StudentForm.razor` (`DataAnnotationsValidator`) |
| **API errors next to the fields** – 400 ValidationProblem mapped to the inputs | `Components/Shared/StudentForm.razor` (`ValidationMessageStore`) |
| **One form for create and edit** – a reusable component | `StudentForm.razor` used by `StudentEdit.razor` (`/students/new`, `/students/{id}/edit`) |
| **Faculty groups** – expand/collapse in C#, no JavaScript | `Components/Pages/Faculty.razor` |
| **Where does the code run?** | `Components/Shared/RuntimeBadge.razor` |

```
SimpleStudentBlazorServer/
├── Program.cs                     ← AddRazorComponents().AddInteractiveServerComponents()
├── appsettings.json               ← "Backends": .NET, PHP, Python (BaseUrl = server → API)
├── ApiClient/                     ← StudentApiClient.g.cs generated by NSwag + generate-client.sh/.ps1
├── Services/ApiConnection.cs      ← selected backend + typed client for it (one per browser tab)
├── Components/
│   ├── App.razor                  ← HTML shell, render mode InteractiveServer for all pages
│   ├── Routes.razor               ← router
│   ├── Layout/                    ← MainLayout (navigation), ApiSwitcher
│   ├── Pages/                     ← Home, Students, StudentDetails, StudentEdit, Faculty
│   └── Shared/                    ← StudentForm, RuntimeBadge
├── wwwroot/app.css                ← same look as the Razor Pages frontend
└── Dockerfile
```

## Run with Docker

From the folder `student-docker-lab-plus-mssql`:

```bash
docker-compose -f docker-compose.infra.yml up -d
docker-compose up --build
```

Open **http://localhost:6031**. In `docker-compose.yml` the backend addresses are Docker service names
(`Backends__0__BaseUrl: http://simplestudentapi:8080`, …), because the Blazor server calls the APIs
inside the Docker network.

## Run locally (dotnet run)

The APIs must be running (Docker, XAMPP or `python main.py`); the defaults in `appsettings.json` are
`localhost:6001` (.NET), `localhost:6002` (PHP) and `localhost:6003` (Python).

```bash
dotnet run
```

Open **http://localhost:6031**. A PHP API in XAMPP runs at another address — change its `BaseUrl` and
`PublicUrl` in `appsettings.json`, e.g. `http://localhost/simpleStudentApi`.

## Regenerate the API client

After the API contract changes (API running on port 6001):

```bash
cd ApiClient
bash generate-client.sh
```

Windows: `.\generate-client.ps1`. Needs Node.js (`npx` downloads NSwag).

## Troubleshooting

| Problem | Fix |
|---|---|
| "Cannot reach the API: Connection refused" | the selected API is not running – start it or choose another one at the top right |
| "Attempting to reconnect to the server…" | the Blazor container was restarted or the network dropped; the page reconnects by itself |
| API switch is lost after F5 | expected: the selection lives in the browser tab's server state, a reload starts a new one |
| Port 6031 is busy | change `applicationUrl` in `Properties/launchSettings.json` |
